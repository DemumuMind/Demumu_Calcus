# Evolve Command System

## Overview

Система анализа и эволюции инстинктов в команды, навыки и агентов.

## Структура

```
.claude/
├── evolve/
│   ├── README.md              # Документация
│   ├── templates/
│   │   ├── command.md         # Шаблон команды
│   │   ├── skill.md           # Шаблон скилла
│   │   └── agent.md           # Шаблон агента
│   └── evolved/               # Сгенерированные файлы
│       ├── commands/          # Эволюционированные команды
│       ├── skills/            # Эволюционированные скиллы
│       └── agents/            # Эволюционированные агенты
├── instincts/                 # Хранилище инстинктов
│   ├── _registry.md           # Реестр инстинктов
│   └── *.md                   # Файлы инстинктов
└── scripts/
    ├── evolve.ps1             # Основной скрипт
    ├── evolve.bat             # Windows wrapper
    ├── evolve.sh              # Unix wrapper
    └── evolve.lang            # Локализация
```

## Использование

### Анализ инстинктов

```bash
evolve
# или
evolve analyze
```

Показывает:
- Общую статистику инстинктов
- Кластеры для эволюции
- Кандидаты в команды/скиллы/агенты

### Генерация файлов

```bash
evolve --generate
# или
evolve generate
```

Создает файлы в `.claude/evolve/evolved/`:
- `commands/` — эволюционированные команды
- `skills/` — эволюционированные скиллы
- `agents/` — эволюционированные агенты

## Типы эволюции

### → Command (Пользовательская команда)

Когда инстинкты описывают действия, которые пользователь явно запрашивает.

**Признаки:**
- "когда пользователь просит..."
- "при создании нового X..."
- Повторяемая последовательность шагов

**Пример:**
- `table-step1`: "при добавлении таблицы, создать миграцию"
- `table-step2`: "при добавлении таблицы, обновить схему"
- `table-step3`: "при добавлении таблицы, сгенерировать типы"

→ **Команда:** `/new-table`

### → Skill (Авто-триггер)

Когда инстинкты описывают автоматические поведения.

**Признаки:**
- Pattern-matching триггеры
- Обработка ошибок
- Проверка стиля кода

**Пример:**
- `prefer-functional`: "при написании функций, предпочитать функциональный стиль"
- `use-immutable`: "при изменении состояния, использовать иммутабельность"

→ **Скилл:** `functional-patterns`

### → Agent (Изолированный процесс)

Когда инстинкты описывают сложные многошаговые процессы.

**Признаки:**
- Отладочные workflow
- Последовательности рефакторинга
- Исследовательские задачи

**Пример:**
- `debug-step1`: "при отладке, сначала проверить логи"
- `debug-step2`: "при отладке, изолировать проблемный компонент"
- `debug-step3`: "при отладке, создать минимальный пример"

→ **Агент:** `debugger`

## Формат инстинкта

```markdown
## INSTINCT: instinct-id
Created: 2024-01-15
Confidence: 85%
Trigger: когда пользователь просит добавить таблицу
Action: создать миграцию базы данных
Domain: database
Scope: project

### Context
[Дополнительный контекст]

### Examples
- Пример 1
- Пример 2
```

## Эволюция

### Правила кластеризации

1. **По домену** — инстинкты из одной области
2. **По триггеру** — инстинкты с похожими условиями
3. **По последовательности** — инстинкты шаг 1, шаг 2, шаг 3

### Пороги уверенности

- **Command:** >= 80% средняя уверенность, 2+ инстинкта
- **Skill:** >= 75% средняя уверенность, 2+ инстинкта
- **Agent:** >= 70% средняя уверенность, 3+ инстинкта
